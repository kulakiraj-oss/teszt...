# RiseMTA UCP

## Indítás

```bash
cd rise-mta-ucp
npm install
npm start
```

Böngésző: http://localhost:3080

## Alap fiókok

| Felhasználó | Jelszó | Szerep |
|-------------|--------|--------|
| `admin` | `RiseAdmin2026!` | admin (teljes jog) |
| `demo` | `demo123` | user + 2 minta karakter |

A jelszavakat a `.env` fájlban tudod cserélni (`ADMIN_USERNAME`, `ADMIN_PASSWORD`).
